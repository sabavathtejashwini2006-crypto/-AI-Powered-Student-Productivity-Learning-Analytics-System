# AI-Powered Student Productivity & Learning Analytics System

A B.Tech Data Science project built with Python and Streamlit.

## Features

- Student dashboard
- Academic analytics
- Productivity analytics
- ML performance prediction
- Personalized study planner
- Smart academic alerts
- AI-style student assistant
- SQLite database initialization
- Sample CSV datasets

## Technology Stack

- Python 3.11+
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- SQLite

## How to Run

1. Open this folder in VS Code.
2. Create a virtual environment:

```bash
python -m venv .venv
```

3. Activate it on Windows:

```bash
.venv\Scripts\activate
```

4. Install requirements:

```bash
pip install -r requirements.txt
```

5. Run:

```bash
streamlit run app.py
```

## Important

The included dataset is demonstration data. For a final academic project, replace it with appropriately collected or synthetic data and document your data-generation/collection method.
